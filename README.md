ONG_Projeto
Sobre o projeto
O ONG_Projeto é um projeto desenvolvido para apresentar uma plataforma voltada para uma organização não governamental (ONG). A aplicação possui páginas para apresentação, cadastro e visualização dos projetos da organização.
________________________________________________________________________________________________________________________________________________________________________________________________________________________________
Funcionalidades:
- Página inicial para apresentação da ONG
- Página de cadastro
- Página para apresentação dos projetos
________________________________________________________________________________________________________________________________________________________________________________________________________________________________
Como executar:
- Não é necessário instalar dependências. Para executar o projeto, basta clonar o repositório e abrir o arquivo index.html em um navegador;
- git clone https://github.com/Oh14g0/ONG_Projeto.git
- Depois, abra o arquivo index.html no navegador.
________________________________________________________________________________________________________________________________________________________________________________________________________________________________
Versionamento
O projeto utiliza Git e GitHub para controle de versão, mantendo o histórico das alterações realizadas durante o desenvolvimento.
